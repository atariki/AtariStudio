# AtariStudio

AtariStudio is an open-source reverse engineering environment for Atari 8-bit software.

## Goals

- Load XEX executables
- Build Atari memory image
- 6502 disassembler
- Control Flow Graph
- Display List analyzer
- Charset viewer
- Screen viewer
- Resource browser
- Robbo Konstruktor analyzer
- Plugin architecture

## Requirements

- Visual Studio 2022
- CMake 3.21+
- C++20

## Build

```bash
mkdir build
cd build
cmake ..
cmake --build .
```

or simply open the repository folder directly in Visual Studio 2022.
